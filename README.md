# Calculadora de Tiempo por Bloques

Una aplicación web interactiva construida con **Python** y **Streamlit** para gestionar y calcular tiempos dedicados a diferentes tareas organizadas por bloques (días).

## 🚀 Características
- **Gestión de Bloques:** Crea y elimina bloques de tareas de forma dinámica.
- **Cálculo Preciso:** Agregue horas, minutos y segundos a cada bloque.
- **Persistencia de Datos:** Los datos se guardan automáticamente en un archivo `datos.json`.
- **Visualización:** Gráficas de barras integradas para comparar el tiempo entre bloques.
- **Modo Offline:** Incluye un script de ejecución rápida para Windows.

## 🛠️ Tecnologías
- Python 3.x
- Streamlit (UI)
- JSON (Almacenamiento local)

## 📦 Instalación
1. Clona el repositorio.
2. Crea un entorno virtual: `python -m venv venv`.
3. Activa el entorno e instala dependencias:
   ```bash
   pip install -r requirements.txt
   ```
4. Ejecuta la app:
   ```bash
   streamlit run app.py
   ```
